# 가입·심사 모바일 화면 시안 v0.2

별도 빌드 없이 `index.html`을 브라우저로 열어 사용할 수 있는 HTML/CSS/JS 프로토타입입니다. Figma 파일이나 Flutter 앱은 아닙니다. 서버·분석 도구·외부 폰트를 연결하지 않습니다.

저장소 루트에서 미리보기:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory design
```

브라우저에서 http://127.0.0.1:8765 를 열고 **체크인 시작하기**를 누릅니다. 각 단계의 **예시로 채우기**로 가상의 데이터를 입력할 수 있습니다. 넓은 화면에서는 왼쪽 화면 목록과 오른쪽 설명을 함께 표시합니다.

## 화면 목록

| ID | 화면 | 다음 단계 조건 | PRD 연결 |
|---|---|---|---|

| account | 계정 만들기 | 이메일 형식, 비밀번호 8자리 이상 | 계정 |
| identity | 본인확인 | 체험 완료 | 가입과 심사 |
| profile | 기본 정보 | 이름·생년월일·성별·활동지역, 만 25세 이상 | 프로필 |
| career | 학력과 직업 | 최종 학력·직업 | 프로필·인증 |
| lifestyle | 생활 정보 | 키·종교·흡연·음주·혼인·자녀 | 프로필 |
| personality | 성격·취미 | 성격 2개, 취미 최대 8개 | 프로필 |
| preferences | 원하는 만남 | 선호 연령·활동지역 | 매칭 조건 |

| photos | 사진 | 필수 3장, 선택 포함 최대 6장, 개별 삭제 | 사진 정책 |
| verification | 추가 인증 | 남성 예시 자료 필수, 여성 선택 | 인증 정책 |
| review | 최종 확인 | 앞선 필수 조건 모두 만족, 확인 체크 | 심사 제출 |
| waiting | 심사 대기 | 가상 접수 상태 표시 | 가입 심사 |
| result | 심사 결과 | 승인·보완·대기·반려 상태 전환 | 가입 심사 |

## 디자인 기준

- 네이비 `#18283c`, 샴페인 골드 `#ac8860`, 아이보리 `#faf9f6`
- 기기 기본 한글 글꼴, 영문 브랜드는 Georgia
- 고정 하단 기본 버튼, 긴 입력 내용은 본문 영역 스크롤
- 선택 태그의 `aria-pressed`, 입력 레이블, 오류 `role=alert`, 키보드 포커스 제공
- 모바일 620px 이하: 전체 화면 / 데스크톱: 기기 프레임과 화면 탐색
- 원본 레퍼런스의 로고·문구·사진을 사용하지 않음

## 구현 범위와 제한

PRD의 가입·프로필 작성·심사 신청·심사 결과까지 15개 화면을 연결한 디자인 검토용입니다. 사진 순서 변경, 실제 이메일 확인, 휴대전화 인증, 외부 파일 업로드, 운영자 심사 처리는 Flutter 및 백엔드 연동 단계에서 구현합니다.

본인확인은 체험 버튼입니다. 실제 인증·회원가입·심사 신청·파일 전송은 실행하지 않습니다. 사진은 기기 안의 Blob URL로 미리보기만 하며 서류는 가상 예시 이름만 표시합니다. 입력값은 메모리에만 두므로 새로고침하면 초기화됩니다. 실서비스의 서버 임시저장은 이 시안에 연결하지 않았습니다.

## 직접 확인한 항목

- 시작 → 동의 → 계정 → 본인확인 → 기본정보 → 학력·직업 → 생활정보 → 성격·취미 → 선호조건 → 자기소개 → 사진 → 인증 → 확인 → 심사 대기 → 심사 결과
- 필수 동의 누락 안내, 민감정보 별도 동의, 마케팅 자동 선택 없음
- 이메일 형식과 비밀번호 길이 검사
- 만 25세 미만 차단
- 성격 2개 초과 선택 차단
- 선호 연령 역전·지역 미선택 안내
- 자기소개 100자 미만 안내
- 필수 사진 3장 미완성 안내
- 사진 최대 6장과 개별 삭제
- 승인·보완·대기·반려 결과 화면 전환
- 예시 데이터로 최종 확인 화면의 전체 요약 반영

디자인 검토 후 화면별 컴포넌트를 Flutter로 옮기고 백엔드 API와 실제 연동합니다.

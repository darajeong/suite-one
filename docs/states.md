# Domain States

## Application

```text
DRAFT -> SUBMITTED -> UNDER_REVIEW
UNDER_REVIEW -> REVISION_REQUESTED -> SUBMITTED
UNDER_REVIEW -> WAITLISTED
UNDER_REVIEW -> APPROVED
UNDER_REVIEW -> REJECTED
WAITLISTED -> UNDER_REVIEW
```

## Introduction

```text
CREATED
-> FEMALE_PENDING
-> FEMALE_ACCEPTED -> MALE_PENDING
-> MUTUALLY_ACCEPTED
-> SCHEDULING
-> CONFIRMED
-> COMPLETED

FEMALE_PENDING -> FEMALE_REJECTED | EXPIRED
MALE_PENDING -> MALE_REJECTED | EXPIRED
MUTUALLY_ACCEPTED | SCHEDULING | CONFIRMED -> CANCELLED
```

## Meeting

```text
SCHEDULING -> CONFIRMED -> AWAITING_ATTENDANCE -> COMPLETED
SCHEDULING | CONFIRMED -> CANCELLED
AWAITING_ATTENDANCE -> DISPUTED -> COMPLETED | CANCELLED
```

## Pass transaction

```text
PURCHASE | GRANT | CONSUME | RESTORE | REFUND | ADMIN_ADJUSTMENT
```

Pass 잔액은 직접 수정하지 않고 거래 원장을 합산해 계산한다. 캐시된 잔액이 필요하면 원장 합계와 정기적으로 대조한다.
